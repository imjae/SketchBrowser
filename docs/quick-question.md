# 일회용 영역 질문

2026-10-28. 앱과 보호된 편집 Worker에 구현했다. API 키 없이 PC의 Codex에 로그인한 ChatGPT 구독 계정으로 합성 질문·빈 이미지의 실제 응답을 확인했다. 전달 대기 오류를 수정한 서버 `ab61af0` 배포와 [APK 0.2.4 빌드·다운로드](https://github.com/imjae/SketchBrowser/actions/runs/40648481454/artifacts/12799355944) 검증을 완료했다. 동일 서명으로 기존 앱 위에 업데이트할 수 있다. 실물 태블릿 재확인은 별도이며 이전 APK 0.2.2에는 이 기능이 없다.

후속 실사용에서 0.2.3의 이미지 전달 대기가 보고됐다. 서버 번들 초기화와 Android origin-only 준비 메시지 처리를 수정하고, 수신 확인·8초 전달 제한·로딩 완료 시 재시도를 추가했다. 배포용 Worker 번들과 Android 메시지 형식을 자동 검사하고 0.2.4 패키지의 수정 코드 포함을 확인했다. 기존 0.2.3은 0.2.4로 업데이트해야 한다. 자세한 결과는 [기능 구현 표](feature-map.md)를 따른다.

## 사용 흐름

1. 페이지에 질문을 쓰거나 설명받을 내용을 화면에 표시한다.
2. 도구막대의 **질문 영역**을 선택하고 펜으로 내용을 한 바퀴 둘러싼다. 그린 선의 내부와 **질문하기 · 취소** 버튼이 표시된다.
3. **질문하기**를 누르면 현재 페이지와 기존 필기를 캡처한다. 선택선과 버튼은 제외하고 자유형 경계 밖은 흰색으로 지운다. 잘라낸 이미지만 서버에 전송한다.
4. 처음에는 패널 안에서 기존 GitHub 소유자 로그인이 필요하다. 이후 짧은 답변 또는 안내가 표시된다. 닫으면 질문·답변을 버린다.

| 이미지 내용 | 표시 결과 |
| --- | --- |
| 읽을 수 있는 질문 | 해당 질문에 2~4문장으로 답하도록 요청 |
| 질문 없이 설명할 문장 | 보이는 문장을 짧게 설명하도록 요청 |
| 질문과 설명할 내용 모두 없음 | 선택한 영역에서 질문이나 설명할 내용을 찾지 못했어요. |
| 흐리거나 잘려서 판독 불가 | 내용을 읽기 어려워요. 영역을 다시 지정해 주세요. |
| 연결·시간 제한 오류 | 오류 안내와 명시적인 다시 시도 |

대화 이어가기, 기록 목록, 자동 질문은 없다. 일반 펜으로 쓴 질문 자체는 기존 노트 필기이므로 기존 저장 규칙을 따른다. **질문 영역 도구의 선택선과 캡처·답변만 일회용**이다.

## 구현과 보관 경계

- `src/ask/engine.ts`: 필기와 분리한 자유형 선택, 영역 표시, 화면 변화 검사, PNG 자르기·마스킹. 손가락은 영역 입력에서 제외하며 S Pen 측면 버튼의 임시 지우기 규칙을 유지한다.
- `src/ask/capture.ts`, `src/browser/BrowserSurface.tsx`: 준비 → 네이티브 WebView 캡처 → 영역 마스킹 → 잠금 해제. 실패하거나 취소되면 원본 전체 이미지를 반환하지 않는다. 이미지는 파일에 쓰지 않고 메모리에서 처리한다.
- `src/ask/useQuestion.ts`, `QuestionPanel.tsx`, `QuestionShell.tsx`: 문서별 임시 상태와 답변 패널. 페이지 이동·닫기 때 취소하며 닫은 뒤 늦은 응답을 표시하지 않는다. 회전할 때 열린 패널 상태를 유지한다.
- 블로그 `server/sketch-question.mjs`, `sketch-question-ui.mjs`: 기존 소유자 인증 뒤 선택 이미지를 현재 연결된 개인 PC 실행기로 중계한다. 고정 형식으로 결과를 검증하고 답변을 평문으로 표시한다.
- `runner/question.mjs`, `codex-question.mjs`: 내부 토큰으로 서버와 연결하며 로컬 Codex app-server의 ChatGPT 로그인을 사용한다. 매 질문마다 임시 스레드에 이미지 data URL 하나를 전달한다. 셸·MCP·브라우저·파일 도구와 작업 공간 접근을 비활성화하고 승인 요청도 거절한다. 질문 실행기는 글 수정 실행기와 별도 프로세스다.

앱의 AsyncStorage·파일, Worker의 Durable Object 저장소·대기열·로그, PC 파일에 질문 이미지나 답변을 기록하지 않는다. Durable Object는 연결과 진행 중 요청만 메모리에 유지한다. 질문 WebView·HTTP 캐시를 끄고 Codex는 `ephemeral: true`를 사용해 로컬 대화 기록을 남기지 않는다. 로그인 상태는 기존 인증 정책대로 보관된다. **OpenAI 측 데이터 보관까지 없어진다는 의미는 아니다.** ChatGPT 계정의 데이터 설정과 서비스 정책은 별도다.

## 연결 설정

기존 소유자 인증과 PC 실행기 설정을 이용한다. `OPENAI_API_KEY`는 필요하지 않으며 ChatGPT 인증 정보를 서버나 앱으로 복사하지 않는다. 개인 PC의 Codex를 원격으로 사용하는 구성이고 ChatGPT 구독 사용량 제한을 따른다. 공개·다중 사용자 AI 서비스용 구성이 아니다. [Codex 인증](https://learn.chatgpt.com/docs/auth), [app-server](https://learn.chatgpt.com/docs/app-server)의 로컬 앱 사용 범위를 따른다.

PC에서 `pnpm question:start`로 시작하고 `pnpm question:stop`으로 종료한다. 기존 `review:start`와 독립적이다. `%USERPROFILE%/.sketch-browser-runner/config.json`의 `questionModel`은 `gpt-6.1-sol`로 설정했으며 질문 추론은 `low`다. 로그인 계정에서 해당 모델을 사용할 수 있어야 한다. PC와 실행기가 켜져 있어야 하며 재부팅 후 다시 시작해야 한다. 자동 시작·절전 방지는 설정하지 않았다.

연결되지 않은 경우 **PC 질문 실행기가 연결되어 있지 않아요. PC에서 실행한 뒤 다시 시도해 주세요.**를 즉시 반환한다. 오프라인 질문 대기열은 없다. 서버 설정은 블로그의 [영역 질문 서버](../../imjae.github.io/docs/SKETCH-QUESTION.md)를 따른다.

## 제한

- 현재 화면 안의 영역 한 개, 최소 32×32 CSS px, 경계 최대 2,048좌표, 전송 PNG base64 최대 4MB다. 열린 선이나 너무 작은 영역은 다시 지정하도록 안내한다.
- 스크롤·내부 스크롤·확대·회전·본문/속성 변경이 감지되면 선택을 해제한다. 내용이 자주 갱신되는 페이지에서는 재선택이 필요할 수 있다. 영상·캔버스의 모든 픽셀 변경을 감지하는 기능은 아니다.
- 새로고침·패널 닫기·앱 종료 뒤에는 질문을 복원하거나 자동 재전송하지 않는다. 재시도는 새 요청 ID로 시작하고 구독 사용량을 추가로 소비할 수 있다. 취소는 PC의 해당 질문 프로세스를 종료하지만 이미 소비한 사용량을 되돌리지는 않는다.
- 모델 답변 제한은 75초, 중계 서버 90초, 화면 100초다. 한 소유자의 연결에서 동시 1개·분당 5회로 제한하며 실행 인스턴스가 재시작되면 분당 카운터가 초기화된다.
- 작은 손글씨, 잘린 수식, 이미지 밖 문맥은 오인식할 수 있다. 빈 영역·판독 불가 분류도 모델 판단이므로 실제 이미지 평가가 필요하다.
- 웹 미리보기에서는 선택·취소·패널 배치만 지원한다. Android 캡처와 로그인·서버 연결은 실물 검증 대상이다.

## 검증

`pnpm typecheck`, `pnpm test`, 웹 개발 서버를 사용한 `pnpm test:e2e`, `pnpm test:question`, `pnpm test:review`로 확인한다. 질문 전용 E2E는 형제 경로 블로그의 실제 요청 처리기·UI·Miniflare 런타임을 사용하며 모델 응답만 테스트 대역으로 바꾼다. 별도 실제 구독 호출에서 합성 질문 “1 + 1은?”의 답 2와 흰색 400×300 이미지의 `no_content`를 확인했다. 이를 다양한 손글씨 인식 품질 검증으로 확대하지 않는다.

자동 검사 범위는 선택선 미저장, 열린 선·터치 제외, 실제 캡처 픽셀과 자유형 마스크, 배율, 엄격한 이미지 CSP, 스크롤·회전·본문 변경, 취소·실패 시 잠금 해제, 빈 영역·판독 불가 안내, 중복 브리지 수신, 새로고침 미복원, 늦은 응답 무시, 가로·세로·390px 패널 배치다. 기존 필기·S Pen·블로그 검토 E2E도 확인한다. 합성 페이지의 검증 캡처는 Git에서 제외한 `test-results/question/`에 생성되며 실제 사용자의 질문 저장 기능이 아니다.

실물 Galaxy Tab에서는 S Pen으로 영역을 둘러싼 뒤 캡처 이미지와 실제 범위의 일치, 확대·회전, 처음 GitHub 로그인, 네트워크 끊김·닫기, 한글 손글씨·수식·빈 영역의 실제 AI 응답을 확인해야 한다. 현재 단위·브라우저 검사를 이 실물 확인으로 대체하지 않는다.
